# AGENTS.md - Dotfiles (Public)

## Scope and Purpose
This repository is public and contains generic configurations, Nix home-manager modules, shell profiles, Neovim configs, and general-purpose development scripts.

## Core Rules for Agents
- **No Sensitive Information**: As a public repository, NEVER commit API keys, personal access tokens, private hostnames, internal IPs, company/institutional credentials, or private repository URLs.
- **Tone and Style**: Clear, technical, and objective. Do not use emojis in code, commits, scripts, or documentation.
- **Separation of Concerns**: Keep business logic or internal corporate data segregated in `.dotfiles-uerj`. Generic engines and portable scripts belong here.
- **Commit Conventions**: Follow Conventional Commits format (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`).
